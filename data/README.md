**Known headline insights already visible in this data:**
- Breast-screening attendance in 2024 ranges from 74.3% (Helsinki) to 85.6% (North Ostrobothnia) — the whole Helsinki-metro cluster (Helsinki, Vantaa-Kerava, East/West/Central Uusimaa) sits at or below the strategy's own 80% participation target while most other counties clear it. See `research/gemini_research.md` §3.
- **Long-wait prevalence (>6 months) varies ~10x across counties in 2024: North Savo 98.1 per 10k vs. South Karelia 9.3 per 10k** — this is the closest thing we have to a direct, quantified, regionally-located treatment-access gap tied to Goal 3's "patients receive treatment within target times" indicator (not cancer-specific, but it's literally the data family THL Guideline 21/2016 — the strategy's own named monitoring mechanism — is built on). See `research/additional_data_sources.md` §1.

**Caveat carried over from `research/additional_data_sources.md`:** none of the waiting-time indicators (13, 5033, 3336) or THL's open procedure-queue cubes break out cancer care as its own monitored category — cancer surgery isn't a tracked queue group in THL's open elective-queue system, consistent with the strategy's own admission that no cancer-specific quality register exists yet. Any claim combining these with cancer-specific indicators should say explicitly that the wait-time figures are for specialised care generally, not oncology specifically.

## `raw/` — original API responses, kept for traceability

- `sotkanet_all_indicators.json` — full THL Sotkanet indicator catalogue (3,797 indicators) with EN/FI/SV titles, fetched from `https://sotkanet.fi/rest/1.1/indicators`.
- `sotkanet_regions.json` — full Sotkanet region hierarchy (540 regions: municipalities, hospital districts, wellbeing counties, etc.), fetched from `https://sotkanet.fi/rest/1.1/regions`.
- `sotkanet_<id>_<name>.json` — raw per-indicator API responses (all regions, all years, `gender=total`) before filtering to wellbeing counties. `10024_eu_standardised_cancer_death_rate.json` is **EU country-level** data (Eurostat region codes), not usable for within-Finland regional comparison — kept only as potential Nordic/EU-benchmark context. Includes the covariate indicators pulled this round: `2331_population_density.json`, `3892_physician_vacancy_rate_health_centres.json` (hospital-district geography, see Covariates section), `2297/2298/2299/2300/3213/3227/3228_kela_travel_*.json` (Kela medical-travel reimbursement, all 7 related measures), and `2616_population_by_region.json` (mid-year population at every region level 2000–2025, pulled purely as **aggregation weights** for population-weighting the broadband and physician-vacancy covariates below, not as an outcome/covariate itself).
- `traficom_broadband_availability_30092025.ods` — original downloaded file (336 rows: national + 19 provinces + 308 municipalities), and its plain pre-aggregation extractions `traficom_broadband_availability_by_municipality.csv` / `..._by_maakunta.csv` — see Covariates section for the population-weighted county rollup.
- `statfin_cancer_deaths_national_2015_2025.json` — raw PxWeb response backing the processed death-by-site CSV.
- `oecd_health_proc_finland_waiting_times.csv` — **525 rows**, Finland-only, from OECD's SDMX data API for the `HEALTH_PROC` "Healthcare utilisation" dataflow (`OECD.ELS.HD:DSD_HEALTH_PROC@DF_KEY_INDIC`). Covers all 7 OECD-tracked elective-surgery wait-time procedures (cataract surgery, PTCA, coronary bypass, **transurethral prostatectomy**, hysterectomy, hip replacement, knee replacement) × 3 measures (mean wait days, median wait days, % waiting >3 months) × years 2000–2024. National-level only (no Finnish sub-national breakdown exists in this dataset). **Not cancer-specific** — prostatectomy here includes benign (BPH) and malignant indications undifferentiated, same caveat as before, now with actual numbers: median prostatectomy wait rose from 39 days (2015) to 63 days (2023), 55 days (2024).
  - **Working query, found by probing the SDMX REST API directly** (the Data Explorer URL in `additional_data_sources.md` §5d is only the interactive-UI link, not a data endpoint): `https://sdmx.oecd.org/public/rest/data/OECD.ELS.HD,DSD_HEALTH_PROC@DF_KEY_INDIC/all?format=csvfilewithlabels` returns the **entire dataflow for all OECD countries** (~285MB CSV, every healthcare-utilisation measure, not just waiting times) — filtered locally in Python to `REF_AREA=FIN` and `MEASURE` in `{WAIT, WAIT_MEAN, WAIT_MEDIAN}`. The `?c[REF_AREA]=FIN`-style server-side filter param was not tried/needed since the full download already worked; a future pull could try that to avoid the 285MB download.
- `thl_sampo_eshjono_queue_groups_latest.csv` — **1,001 rows**, from THL's Sampo pivot-cube system (`sampo.thl.fi/pivot`), cube `eshjono` ("Toimenpidettä odottavat ja odotusajat jonoryhmittäin" — patients awaiting a procedure and wait times, by queue group). Covers **all 27 named elective-procedure queue groups** (cataract, hip/knee replacement, hysterectomy, BPH treatment, tonsillectomy, etc.) + an "all queue groups" aggregate, × 18 producers (the 23 wellbeing counties collapse to 18 rows here because HUS-area counties report jointly under "HUS" and a few small counties are grouped with a neighbour in this particular cube) × 3 measures (total waiting n, % waiting >90 days, % waiting >180 days), snapshot as of **30.09.2026** (the latest available period; the cube also has monthly data back to 2016, not pulled here).
  - **Confirms, with actual queried values (not just dropdown labels), that cancer surgery is not a monitored queue group in this system** — none of the 27 groups is cancer-specific; the two cancer-adjacent-sounding ones ("Eturauhasen liikakasvun toimenpide" / BPH treatment, "Rintarauhasen pienennys- tai muovausleikkaus" / cosmetic breast reduction) are confirmed benign/cosmetic, not oncology.
  - **No PXWeb-standard JSON-stat API exists at a `/PXWeb/api/` path**, but the site's own frontend calls a working, undocumented JSON-stat endpoint directly: loading `https://sampo.thl.fi/pivot/prod/fi/eshjono/jonoryhma/summary_jonoryhma2?jono_0=<procedure_code>&mittarit_0=<measure_code>` (plain GET, any `User-Agent`, no auth) returns an HTML page whose `data-ref="fact_eshjono_jonoryhma.json?..."` attribute contains a freshly-generated, opaque query-token URL; fetching `https://sampo.thl.fi/pivot/prod/fi/eshjono/jonoryhma/<that data-ref>` returns clean JSON-stat 2.0. Procedure/measure codes were read directly off the page's `<select>` option values. Iterated over all 27×3 combinations to build this CSV; script not checked into the repo (one-off, in session scratchpad).
- `nordcan_finland_incidence_mortality_trends_1971_2024.csv` — **648 rows**, Finland national incidence and mortality, annual 1971–2024, for 6 cancer sites (all sites, breast, prostate, colorectal, lung, cervix uteri): case/death counts, population, crude rate, and age-standardised rates (world/European/Nordic standards).
- `nordcan_finland_5yr_relative_survival.csv` — **199 rows**, Finland relative survival (%, with confidence intervals) by 5-year diagnosis-period bucket (1975–1979 through 2020–2024), same 6 cancer sites, **at 1/5/10 years post-diagnosis** (`time_years` column — despite the filename, this file is not 5-year-survival-only; filter `time_years==5` for the headline 5-year figure). E.g. prostate-cancer **5-year** survival (`time_years=5`) rose from 48.9% (1975–1979) to 94.2% (2020–2024). *(Corrected 2026-11-13: the background agent that pulled this data wrote an incorrect example in its own summary — 85.0%→90.4% — which mixed the 1-year value for 1975–1979 with the 10-year value for 2020–2024. Verified by reading the CSV directly before trusting the claim.)*
  - **Both pulled from NORDCAN's real backend API**, previously thought to 404 on every guessed path. The actual path structure (found by downloading and grepping the live Vue/Vite JS bundle — `https://nordcan.iarc.who.int/assets/main-CSBjvrOB.js` plus lazy-loaded chunks `Tables-*.js` and `SurvivalBars-*.js` — for the literal URL-building code) is **`{api_url}/data/population/{type}/{sex}/({country})/({cancer})/?ages_group=0_17&year_start=Y1&year_end=Y2&year_grouped=0|1`** for incidence/mortality (`type`: 0=incidence, 1=mortality; `sex`: 0=both, 1=male, 2=female) and **`{api_url}/survival/population/1_5_10/{sex}/({country})/({cancer})/?surv_period=5|10`** for relative survival — both confirmed working against `https://canapi.iarc.who.int/api/nordcan/v2/961` (`961` = current `default_db` version; `246` = Finland's NORDCAN/ISO-numeric country code, found via `.../961/meta/populations/all/`; cancer-site IDs, e.g. 980=All sites, 180=Breast, 240=Prostate, 520=Colorectal, 160=Lung, 190=Cervix uteri, found via `.../961/meta/cancers/all/`). This supersedes the prior "dead end, view/export-only" conclusion for bulk programmatic access — NORDCAN's `canapi.iarc.who.int` backend is a real, queryable, unauthenticated JSON API once the exact path shape is known; it's just undocumented.

## How the data was pulled (for reproducibility)

- **THL Sotkanet**: REST API at `sotkanet.fi/rest/1.1/`. Requires a `User-Agent` header (Cloudflare blocks default `curl`/Python UAs). The `regions=`/`region=` query parameter is accepted but **silently ignored by the API** — it always returns all regions; filtering to the 23 wellbeing counties was done locally in Python using `sotkanet_regions.json`. The `years=` parameter must be **repeated** (`years=2016&years=2017&...`); comma-separated or dashed ranges both return `400 Bad Request`.
- **Statistics Finland (Tilastokeskus)**: PxWeb API at `pxdata.stat.fi/PxWeb/api/v1/en/StatFin/ksyyt/11az.px`, POST with a JSON-stat2 query body (see table metadata for valid codes). No wellbeing-county breakdown was found in this particular table (`11az`) — it's national-only by age/sex/cause/year.

## Cancer Registry screening reports — now covering all 3 programmes (see `research/cancer_registry_screening_reports.md`)

`cancerregistry.fi` (English) is a **different, non-blocked** access point from `syoparekisteri.fi` below — it links to three large annual reports (breast/cervical/colorectal) hosted at `stats.cancerregistry.fi`, accessible via plain `curl`. Each report mixes a few genuinely interactive charts (real embedded Plotly JSON — exact numbers) with dozens of static base64-PNG charts (no underlying data table found; read visually).

- **`data/processed/cancerregistry/*.csv`** (exact, parsed from embedded JSON, not chart-reading): national participation & positivity rate by age group and year, for all three programmes — breast 2010–2024, **cervical 1991–2024**, colorectal 2022–2024 only (confirms colorectal is by far the newest programme).
- **`data/raw/cancerregistry_screening_reports/*.png`** (14 images, visually read — see the research note for every number): cancer-specific diagnostic-delay by wellbeing county for **all three** cancer types (breast→diagnostics, cervical→colposcopy, colorectal→colonoscopy) — this is the cancer-specific wait-time data §1 of `additional_data_sources.md` concluded didn't exist anywhere, now found; plus participation by education/nativity/region-of-birth for all three types.
- **Headline, now cross-checked across cancer types**: Helsinki is worst-or-near-worst for breast and cervical diagnostic delay (persistently, 2+ years running) but only middling for colorectal (North Savo and Päijät-Häme are worst there). North Savo is the *fastest* county for cervical but the *worst* for colorectal. **No single county is uniformly "the problem"** — a credible tool has to report per cancer type.

## Covariates — what structurally predicts the gaps (see `research/covariate_correlation_analysis.md`)

Pulled to move from "where are the gaps" to "what explains them, quantitatively":

- `covariates_immigrant_background_by_wellbeing_county.csv` — % foreign-language speakers, % foreign background, by county, 2024. Source: StatFin `vaerak/159t.px`, aggregated from 308 municipalities up to the 23 counties via the `memberOf` mapping in `sotkanet_regions.json`.
- `covariates_income_poverty_by_wellbeing_county.csv` — median disposable income, at-risk-of-poverty rate, by county, 2023. Source: StatFin `tjt/14ww.px`, same aggregation method.
- `traficom_broadband_availability_by_wellbeing_county.csv` — **24 rows** (23 counties + whole country), fixed-network broadband availability as % of households able to get ≥30/100/300/1000 Mbit/s, snapshot 30.9.2025. Source: Traficom's own open statistics page `tieto.traficom.fi/en/statistics/fixed-broadband-availability`, which links a direct downloadable file (not an API) — `https://www.traficom.fi/files/media/file/Kiintean-verkon-laajakaistasaatavuus-Tillgang-till-fasta-natet.ods`, a 336-row ODS with national (1 row) + 19-maakunta (province) + 308-municipality breakdowns. The province level doesn't match wellbeing-county boundaries (Uusimaa is 1 province but 5 wellbeing counties), so **county figures here were built from the 308 municipality rows**, population-weighted (weights = THL Sotkanet indicator 2616, mid-year population by municipality) and aggregated via each municipality's `memberOf` → `HYVINVOINTIALUE` link in `sotkanet_regions.json` — same method the README's intro recommends. All 308 municipalities matched (2 needed a manual name alias: Traficom's ODS spells them "Maarianhamina"/"Pedersöre", Sotkanet uses "Maarianhamina - Mariehamn"/"Pedersören kunta"). Raw inputs kept at `data/raw/traficom_broadband_availability_30092025.ods` (original file), `data/raw/traficom_broadband_availability_by_municipality.csv` and `..._by_maakunta.csv` (plain extraction, pre-aggregation). Gigabit (≥1000 Mbit/s) coverage ranges from 37.9% (Kainuu) to 93% (North Ostrobothnia) — fiber buildout, not just "any broadband," is where the real regional gap is; the ≥30 Mbit/s tier is >70% almost everywhere.
- `kela_medical_travel_reimbursement_by_wellbeing_county.csv` — **624 rows**, Kela-reimbursed medical travel (taxi/ambulance/own-car trips to health appointments under the sickness insurance act) by county and year, 2000–2025: total € reimbursed, total € cost (pre-reimbursement), number of trips, number of users, and three per-capita/per-client ratios. Source: THL Sotkanet indicators **2297** (total reimbursements, EUR 1000), **2298** (total costs), **2299** (trip count), **2300** (user count), **3213** (€/capita), **3227** (cost €/capita), **3228** (cost €/client) — all of these are THL's regionalised republication of Kela's own figures, queried the same way as every other Sotkanet indicator in this repo (`User-Agent` header, repeated `years=`). Raw per-indicator JSON at `data/raw/sotkanet_<id>_kela_travel_*.json`. **Verifies the previously-uncited Gemini-research claim of "€311M in 2021": the national total (region "Whole country") for indicator 2297 in 2021 is exactly 311,108 thousand euros = €311.108M — confirmed correct against this primary source.** By county in 2024, €/capita ranges from €22.4 (Helsinki) to €145.8 (Kainuu) and €141.2 (Lapland) — a >6x spread that tracks rurality/distance far more cleanly than any of the outcome gaps tracked so far; national 2024 total was €343.9M (up from €311M in 2021, i.e. reimbursement spend has kept rising since the figure was quoted). Kela's own `tietotarjotin.fi` statistics-portal pages for this same series (`sairausvakuutuksen-matkakorvaukset-hyvinvointialueittain`) exist but are JS-rendered and didn't return usable content to an automated fetch — Sotkanet's republication of the identical Kela-sourced numbers was used instead since it's directly machine-readable and matches our existing pipeline.
- `physician_vacancy_rate_by_wellbeing_county_legacy_2004_2022.csv` — **437 rows**, % of health-centre physician positions that were vacant ("lääkärivaje"), i.e. a direct physician-shortage proxy. Source: THL Sotkanet indicator 3892, found by searching the catalogue (`data/raw/sotkanet_all_indicators.json`) for "lääkäri". **Caveat: this series is only published at the pre-2023 hospital-district (`sairaanhoitopiiri`) geography and stops in 2022** — the year the wellbeing-county reform took effect — because Sotkanet's own region hierarchy does not link `HYVINVOINTIALUE` to `SAIRAANHOITOPIIRI` via `memberOf` (it links to `ERVA` catchment areas instead). Reprojected onto the 23 wellbeing counties using a manually-documented crosswalk (in the processing script, not checked in) based on the known 2023 reform mapping: 15 hospital districts map 1:1 to a wellbeing county; Itä-Savo+Etelä-Savo merge into South Savo and Länsi-Pohja+Lappi merge into Lapland (population-weighted mean of the two, weights from Sotkanet indicator 2616); the old HUS district splits into 5 counties (Helsinki, Vantaa-Kerava, East/West/Central Uusimaa), which all inherit the **same** HUS-wide value since no finer historical breakdown exists — this is flagged per-row in an `aggregation_method` column. 2022 values range from 0% (Kanta-Häme, Kymenlaakso, Åland) to 35.3% (North Karelia) and 22.1% (South Karelia) — a stark, pre-reform physician-access gap.
- `2331_population_density_by_wellbeing_county.csv` — **504 rows**, population/km², THL Sotkanet indicator 2331, 2005–2025, no aggregation needed (already published at wellbeing-county level). The cleanest, longest-running structural covariate pulled this round — e.g. 2024 density ranges from ~3/km² (Lapland) to >1,000/km² (Helsinki).

**Correlated against our 2024 outcome data (n=22–23 counties — directional, not statistically powered):** % foreign background correlates strongly with *lower* breast-screening attendance (r=−0.85) — consistent with the Cancer Registry's own individual-level finding, so this one's trustworthy. **Median income also correlates strongly negative (r=−0.81) but this is a confound/ecological-fallacy trap, not a real finding** — it only looks that way because Finland's wealthiest counties are also its most immigrant-dense; the Cancer Registry's individual-level data shows the opposite (higher income → *higher* attendance) and should be trusted over this county-level number. None of these covariates meaningfully explain the long-wait (>6mo) gap (all |r| ≤ 0.27) — that gap looks like a supply-side capacity issue, not a demand-side access issue. Full reasoning and the ecological-fallacy explanation in the research note — read it before citing the income correlation anywhere.

**Quick exploratory checks on the four new covariates above (same small-n caveat, not in the research note, treat as a starting point not a conclusion):** gigabit broadband coverage vs. 2024 breast-screening attendance, r=−0.31 (n=23, weak, wrong-signed if read naively as "connectivity helps" — more likely both are confounded by rurality in opposite ways); Kela travel-reimbursement €/capita (2024) vs. population density (2024), r=−0.44 (n=24, moderate, in the expected direction — sparser counties claim more travel reimbursement per person); 2022 physician-vacancy % vs. 2022 long-wait (>6mo) prevalence, r=0.10 (n=17, essentially no relationship — consistent with the existing finding above that the long-wait gap looks supply/capacity-driven in a way these particular covariates don't explain).

Aggregating the raw national grid to 23 counties would require real GIS work (routing engine + nearest-hospital assignment per grid cell) well beyond a quick covariate pull — flagging as a dead end per the brief's own instruction, rather than spending more effort here.
